# Flujograma de síncope en urgencias

Flujograma interactivo para el manejo del síncope en urgencias, con dos vistas: un **mapa** completo del algoritmo y un **recorrido guiado** paso a paso pensado para el móvil. Integra la guía ESC 2018, el consenso EUSEM 2024 y revisiones de 2024-2026, con las referencias citadas en cada apartado.

**🌐 Ábrelo en la web: [xino00.github.io/flujograma-sincope](https://xino00.github.io/flujograma-sincope/)**

Forma parte de los apuntes [MIR · Medicina Familiar y Comunitaria](https://mirapuntes.pages.dev).
